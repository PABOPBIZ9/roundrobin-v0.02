# Typography

Drop licensed font files into `../Typography/DROP-FONTS-HERE/`.

## Current site stack

| Role | Family | Notes |
|------|--------|-------|
| Display / headlines | Bebas Neue (or site `--display`) | Tall condensed sports display |
| Body / UI | DM Sans / system UI stack | Readable on mobile |

## Rules

1. Never redraw the **PGB** wordmark with a substitute font for logo use — always use logo files.
2. Headlines can echo the blocky sports feel; body stays clean and highly legible.
3. Minimum body size on mobile: **16px**.
4. Avoid default “AI starter” stacks (Inter / Roboto / Arial) for marketing heroes when licensed display fonts are available.

## Drop checklist

When adding fonts, include:

```
Typography/DROP-FONTS-HERE/
  Display/
    FontName-Bold.woff2
    FontName-Bold.otf
  Body/
    FontName-Regular.woff2
    FontName-Medium.woff2
  LICENSE.txt
```
