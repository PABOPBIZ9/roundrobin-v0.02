# Logo overview

PGB has four logo families. Pick the smallest family that still reads clearly at the size you need.

## 1. Primary (vertical)

Full badge: stars + tower + **PGB** wordmark stacked.  
**Default for:** splash, posters, merch centers, membership cards.

- Prefer `Logos/Primary/Color/` on light or photographic backgrounds with clear contrast.
- Prefer `Gold` or `Platinum` on dark UI and arena screens.

## 2. Horizontal

Badge + wordmark in a wide lockup.  
**Default for:** website header, email header, presentations, sponsor boards.

## 3. Icon / emblem

Stars + tower only (or circle emblem).  
**Default for:** favicons, avatars, app icons, tight UI chrome.

## 4. Wordmark

**PGB** letterforms only.  
**Default for:** secondary branding, text-heavy layouts, when the icon already appears nearby.

## File formats

| Format | Use |
|--------|-----|
| **SVG** | Web, UI, anything that scales (preferred) |
| **PNG (transparent)** | Social, decks, when SVG isn’t supported |
| **PNG On-White / On-Midnight** | Quick drops onto flat backgrounds |
| **PNG Square** | Profile / avatar crops |

## Approved colorways

| Colorway | Background |
|----------|------------|
| Full Color | Light / photo (high contrast) |
| Midnight | Light |
| White / Mono-Light | Dark |
| Gold | Dark / midnight |
| Platinum | Dark / midnight |

Never invent new logo colors. Use the palette in `Colors/`.
