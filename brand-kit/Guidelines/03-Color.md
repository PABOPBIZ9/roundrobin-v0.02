# Color

Tokens live in `../Colors/colors.json`. Swatch PNGs live in `../Colors/swatches/`.

| Token | Hex | Role |
|-------|-----|------|
| Platinum | `#E5E7EB` | Light metal, UI chrome, platinum tier |
| Championship Gold | `#D4AF37` | Primary brand metal / OG Gold |
| Champagne | `#F5E6B3` | Soft gold highlight, secondary |
| Ruby | `#A6122F` | Energy / alert / accent |
| Sapphire | `#0047A1` | Trust / links / secondary accent |
| Midnight | `#000000` | Primary dark ground |

## Logo color rules

1. Use **approved logo colorways only** (do not recolor SVG fills ad hoc).
2. Full-color logos keep internal gold / platinum / ruby relationships intact.
3. Mono logos are only Midnight or White (or approved Gold / Platinum single-ink versions).

## Surfaces

- **Midnight** backgrounds → Gold, Platinum, or White logos  
- **White / Platinum** backgrounds → Midnight or Full Color logos  
- **Ruby / Sapphire** fields → White or Platinum logos (test contrast)
