# Brand Factory

Batch marketing system for **PUMPSLUT** · **BADMONZ** · **BOMBPOPZ** · **PuckGoldBiz**.

## Open

[studio.html](./studio.html) — brand switcher + kit + promo batch + fan banners

## What it does

1. **Brand kit** (MonkeDAO / Uber newsroom shape) — stacked/horizontal marks, icon fill/outline, color swatches, type, voice
2. **Promo batch** — Amazon/Target-style deal walls (hero, join bar, price tiles, category tiles, premium strip) → PNG export for Twitter / email / stories / billboard ratios
3. **Fan / supporter banners** — Cirrus-style framed avatar + `@handle` + “Now on …” CTA; paste a list of early fans and mint a batch
4. **Refs** — layout references (not competitor product plugs)
