# PGB Brand Kit

Official logo system for **PuckGoldBiz (PGB)**.

## Colors
| Token | Hex |
|-------|-----|
| Platinum | `#E5E7EB` |
| Championship Gold | `#D4AF37` |
| Champagne | `#F5E6B3` |
| Ruby | `#A6122F` |
| Sapphire | `#0047A1` |
| Midnight | `#000000` |

## Folders
- `lockup/` — primary vertical badge, horizontal lockup, color variants
- `icon/` — stars + tower mark (color + mono)
- `wordmark/` — PGB wordmark variants
- `app/` — app / social icons
- `favicon/` — 16–512 + `.ico`
- `mockup/` — stadium jumbotron usage
- `png/` — master exports

Each asset includes transparent PNG plus `-on-white`, `-on-midnight`, and `-square` variants where applicable.

## Usage
- **Website header:** `lockup/horizontal-lockup.png` or `lockup/primary-master.png`
- **Favicon:** `favicon/favicon.ico`
- **App icon:** `app/apple-touch-icon.png`
- **Dark backgrounds:** gold / platinum / white versions
- **Light backgrounds:** midnight / full-color badge
