NHL-style awards case — drag/drop finals into each trophy folder.

```
assets/vault/trophies/
  puckgold-cup/
  underdog-banner/
  finalist-plate/
  golden-gecko/          # Playoff MVP
  hart-puck/             # Season MVP
  golden-stick/          # Scoring
  snipers-orb/           # Most goals
  wall-trophy/           # Best goalie
  blue-line-blade/       # Top D
  calder-spark/          # Rookie
  clutch-award/
  conductors-crest/      # Sportsmanship
  neon-night/            # Most fun
  booth-bomb/
  founding-spirit/
  district-thunder/
  fan-farmer/
  outfit-oracle/
```

Each folder: `trophy.png`, `trophy-hero.jpg`, `icon.png`, optional `lore.md`.

Page: `awards.html` · Data: `assets/js/awards-data.js`
